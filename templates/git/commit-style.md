# Commit message style guide

Write commit messages like an engineer who owns the subsystem:

1. **Imperative, specific subject under 72 characters**:
   - Good: `Raise Arabic body line-height to 1.80 and zero letter-spacing`
   - Good: `Calculate 40ft high-cube demurrage from day 6 onward`
   - Bad: `✨ feat: enhance UI/UX and fix issues`
   - Bad: `Update index.html`
2. **Zero AI trailers or tool badges**: Never include `Co-Authored-By: Claude`, `Generated with Claude Code`, or robot emojis.
