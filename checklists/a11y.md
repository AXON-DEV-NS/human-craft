# Accessibility checklist (WCAG 2.2 AA)

- [ ] `scripts/contrast-check.mjs` and `scripts/a11y-audit.mjs` pass (`>= 4.5:1` body contrast).
- [ ] Every `<input>` and `<select>` has an explicit `<label for="...">`.
- [ ] Visible `:focus-visible` ring (`2px solid`) on every interactive element; zero bare `outline: none`.
- [ ] Viewport meta tag allows pinch-to-zoom (no `user-scalable=no`).
