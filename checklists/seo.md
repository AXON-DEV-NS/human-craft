# SEO and metadata checklist

- [ ] `scripts/scan-seo.mjs` passes with unique `<title>` and `<meta name="description">` per page.
- [ ] Zero `<meta name="generator">` tags or `?utm_source=chatgpt.com` query strings.
- [ ] OpenGraph `og:image` points to a real domain asset (never `lovable.dev` or `example.com`).
