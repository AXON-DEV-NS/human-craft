# Git history and repository hygiene

1. **Atomic, imperative commits**: Write commit messages that explain what changed and why (`Add Alexandria Port 2026 storage tier rates`).
2. **Zero AI trailers or badges**: Never include `Co-Authored-By: Claude`, `Generated with Claude Code`, or emoji prefixes (`✨ feat:`) in commit logs.
3. **No agent dotfiles in client repos**: Remove `.cursorrules`, `CLAUDE.md`, `.windsurfrules`, `.clinerules`, and `.bolt/` before client handoff.
