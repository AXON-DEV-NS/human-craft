# Domain-driven naming

Replace generic LLM placeholders (`data`, `res`, `item`, `handleClick`, `processData`, `Component1`, `utils.ts`) with domain nouns and verbs:

- Variables: `customsManifest`, `billableDays`, `unpaidInvoicesCents`
- Functions: `calculateDemurrageEgp()`, `parseEtaWebhookSignature()`
- Components: `WaybillTimeline`, `TariffTierTable`
