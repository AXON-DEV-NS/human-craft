# Technical SEO checklist

1. **Unique `<title>` and `<meta name="description">`** on every route.
2. **Canonical URL and OpenGraph**: Include `<link rel="canonical">`, `og:title`, `og:description`, and a real `1200x630` `og:image` hosted on the production domain.
3. **No `<meta name="generator">`**: Strip generator tags from build output.
