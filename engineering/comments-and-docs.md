# Comments and documentation

1. **Explain why, never what**: Delete every comment that restates the next line of code (`// Initialize state`, `// Render component`, `// Import dependencies`).
2. **Valid comment subjects**: Regulatory formulas (`// Egyptian Tax Authority e-Invoice spec v1.0 requires half-even rounding`), browser bugs, or performance invariants.
3. **No ASCII section banners**: Delete `// ====== HELPERS ======` dividers.
