# Playbook: Product landing page

## 1. Non-template section orders

- **Order A (Proof-first)**: 1. Live interactive tool or concrete problem demo -> 2. Technical specification table -> 3. Verified named case study -> 4. Transparent pricing.
- **Order B (Specification-first)**: Open immediately with the interactive filter/table above the fold, followed by methodology and direct action.
- **Order C (Editorial narrative)**: Lead with a documented customer problem and cost breakdown, then show the step-by-step resolution.

## 2. What to cut

- Cut sparkle badges, unverified logo marquees, 3-icon feature cards, and bottom 'Ready to transform?' banners.

## 3. Required real content

- Exact product mechanism, real screenshots or live calculator, pricing numbers, and verified customer quote. (If any item is missing, mark `[CLIENT INPUT NEEDED]` in `client-todo.md`).
