# Playbook: 404 and error pages

## 1. Non-template section orders

- **Order A (Proof-first)**: 1. Clear status code (`404 Page Not Found`) -> 2. Direct links to top 4 active routes -> 3. Search input or support contact.
- **Order B (Specification-first)**: Open immediately with the interactive filter/table above the fold, followed by methodology and direct action.
- **Order C (Editorial narrative)**: Lead with a documented customer problem and cost breakdown, then show the step-by-step resolution.

## 2. What to cut

- Cut 'Whoops! Looks like you're lost in space 🚀' copy and broken links.

## 3. Required real content

- Valid navigation links back to the main application. (If any item is missing, mark `[CLIENT INPUT NEEDED]` in `client-todo.md`).
