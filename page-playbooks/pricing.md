# Playbook: Pricing page

## 1. Non-template section orders

- **Order A (Proof-first)**: 1. Tier comparison table anchored on usage units -> 2. Interactive cost estimator -> 3. Included baseline guarantees -> 4. Billing & cancellation FAQ.
- **Order B (Specification-first)**: Open immediately with the interactive filter/table above the fold, followed by methodology and direct action.
- **Order C (Editorial narrative)**: Lead with a documented customer problem and cost breakdown, then show the step-by-step resolution.

## 2. What to cut

## 3. Required real content

- Exact currency, billing cadence, overage unit rates, and refund policy. (If any item is missing, mark `[CLIENT INPUT NEEDED]` in `client-todo.md`).
