# Playbook: Documentation site

## 1. Non-template section orders

- **Order A (Proof-first)**: 1. Copy-pasteable quickstart command -> 2. Architecture & request/response schema -> 3. Authentic domain examples -> 4. Error code reference table.
- **Order B (Specification-first)**: Open immediately with the interactive filter/table above the fold, followed by methodology and direct action.
- **Order C (Editorial narrative)**: Lead with a documented customer problem and cost breakdown, then show the step-by-step resolution.

## 2. What to cut

- Cut marketing fluff in docs, `foo`/`bar` placeholders, and unrunnable pseudo-code.

## 3. Required real content

- Working code snippets, exact CLI flags, HTTP status codes, and version number. (If any item is missing, mark `[CLIENT INPUT NEEDED]` in `client-todo.md`).
