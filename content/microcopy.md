# Microcopy: buttons, labels, and hints

- **Buttons**: Verb + specific object (`Download tariff PDF (1.4 MB)`, `Create sandbox API key`, `احجز موعد معاينة`). Never `Learn More`, `Get Started`, or `Click Here`.
- **Form labels**: Always visible above the input (`Work email`, `رقم البطاقة الضريبية`). Never hide the label inside `placeholder`.
- **Helper text**: Place format rules below the label (`9 digits without dashes, e.g. 418290512`) before the user types, not only after validation fails.
