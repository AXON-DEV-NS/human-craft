# Iconography rules

1. **Banned default quartet**: Do not use Lucide `Sparkles`, `Zap`, `Rocket`, or `Shield` as feature-card fillers.
2. **No emoji icons**: Never place `🚀`, `✨`, `💡`, or `🔥` inside colored icon squares.
3. **Consistent stroke geometry**: Every icon in a project must share one stroke width (`1.5px` or `1.75px` at a `24x24` viewBox), one join style (`stroke-linejoin: round` or `miter`), and `aria-hidden="true"` when paired with a text label.
4. **When to use numbers instead**: If a section explains a 3-step or 4-step workflow, use tabular numerals (`01`, `02`, `03`) rather than metaphorical icons.
