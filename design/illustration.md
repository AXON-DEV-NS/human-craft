# Technical illustration and diagrams

When photography is unavailable, build domain-accurate SVG diagrams rather than pasting generic 3D clay blobs:

- **Annotated schematics**: Use `1px` vector strokes in `var(--color-ink)`, callout leader lines, and monospace dimension labels (`140 mm`, `HTTP 200 OK`, `CIF + 14% VAT`).
- **Inline accessible SVG**: Include `<title>` and `<desc>` inside informational `<svg>` diagrams so screen readers announce the diagram content.
