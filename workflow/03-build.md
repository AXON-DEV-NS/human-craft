# Phase 3 — Token-first build

**Required output**: `templates/tokens/tokens.css`

## Steps

1. Write `tokens.json`, `tokens.css`, `type-scale.css`, `spacing-scale.css`, and `motion-tokens.css` first.
2. Build semantic HTML landmarks (`<header>`, `<nav>`, `<main id="main-content">`, `<footer>`) with real domain copy.
3. Implement all five component states (ideal, empty, loading, error, edge-case overflow) using logical CSS properties (`margin-inline-start`, `padding-inline-end`).
