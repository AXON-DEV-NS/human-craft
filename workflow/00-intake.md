# Phase 0 — Intake and content inventory

**Required output**: `templates/brief/client-brief.md`

## Steps

1. Collect the real organization name, domain, target buyer, and primary user action.
2. Inventory all existing copy, audited metrics, photos, and legal details in `templates/brief/content-inventory.md`.
3. Never invent missing testimonials, client logos, or statistics. Log every missing item in `templates/reports/client-todo.md` with `[CLIENT INPUT NEEDED: ...]`.
