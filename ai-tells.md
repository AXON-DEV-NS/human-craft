# AI tells overview (one-page hub)

Machine-generated interfaces fail because they substitute statistical averages for specific decisions. Every layer—visuals, copy, markup, code, git history, and file metadata—can carry generator tells.

## Quick severity summary

- **S0 (Blocker)**: `lorem ipsum`, `href="#"`, `example.com`, `.cursorrules`/`CLAUDE.md` in client repos, `lovable-tagger`, `gptengineer.js`, fake testimonials, positive `letter-spacing` on Arabic text. Must be **0**.
- **S1 (High-confidence tell)**: Indigo-violet-pink hero gradients, `bg-clip-text` headlines, sparkle pills, banned hype verbs (`elevate`, `seamless`, `ارتقِ بتجربتك`, `حلول مبتكرة`), 3 identical icon-top cards. Must be **0**.
- **S2 (Structural habit)**: Uniform `py-20` spacing across all sections, generic `handleClick` identifiers, redundant narration comments (`// Initialize state`), uncalibrated default font stacks.
- **S3 (Soft signal)**: Minor stylistic defaults logged in the audit report.
