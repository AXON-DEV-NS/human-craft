# Severity model (S0 to S3)

| Severity | Definition | Release gate |
|---|---|---|
| **S0** | Explicit generator artifact, placeholder (`Lorem ipsum`, `href="#"`, `example.com`), agent config file (`.cursorrules`), or broken Arabic script (`letter-spacing > 0`). | **0 allowed** |
| **S1** | High-confidence machine tell: indigo-violet-pink hero gradient, sparkle badge, banned hype vocabulary (`elevate`, `seamless`, `ارتقِ بتجربتك`), or 3 identical icon cards. | **0 allowed** |
| **S2** | Structural or stylistic habit: identical vertical padding across 4+ sections, `handleClick` identifiers, or narrating comments. | `< 5` with written justification |
| **S3** | Minor stylistic preference recorded for editorial review. | Logged in report |
