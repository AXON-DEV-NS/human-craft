# التخطيطات ثنائية اللغة (Bilingual Arabic/English layouts)

1. **مبدّل اللغة الواضح**: اعرض اسم اللغة بلغتها الأم (`العربية` في الواجهة الإنجليزية، و`English` في الواجهة العربية) دون استخدام أعلام الدول.
2. **ثبات الشبكة عند قلب الاتجاه**: بالاعتماد على CSS Grid والخصائص المنطقية (`inline-start` / `inline-end`)، تنقلب الشبكة تلقائيًا عند تغيير `dir="rtl"` دون الحاجة لملف CSS منفصل.
