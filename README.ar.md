# human-craft — دليل الصنعة البشرية للمواقع والتطبيقات

`human-craft` هي مهارة وكيل ذكاء اصطناعي (Agent Skill) وحزمة فحص آلي مفتوحة المصدر لبناء ومراجعة وتنظيف المواقع وتطبيقات الويب والنصوص العربية والإنجليزية والأكواد البرمجية والمستودعات والعروض المتحركة المبرمجة، بحيث تخرج كل طبقة فيها بقرارات هندسية وتصميمية مدروسة لا أثر فيها للقوالب الآلية المكررة.

## المشكلة التي تعالجها الأداة

تتشابه المواقع المولدة آليًا لأنهاتركز على القيم الافتراضية السهلة: تدرجات البنفسجي والوردي في الترويسة، ثلاث بطاقات متماثلة بأيقونات جاهزة، خطا `Cairo` أو `Tajawal` بارتفاع سطر ضيق وتباعد حروف مقطّع، وعبارات مترجمة حرفيًا مثل "ارتقِ بتجربتك" و"في عالم يتسارع"، إلى جانب روابط `href="#"` وبقايا ملفات الأدوات مثل `.cursorrules` و`lovable-tagger`.

لا تكتفي هذه المهارة برصد العلامات وحذفها، بل تلزم الوكيل بكتابة **وثيقة اتجاه (Direction Statement)** من صفحة واحدة تحدد الخطوط، ونسب الألوان (`60/30/10`)، وإيقاع المسافات، والسجل اللغوي العربي المناسب للجمهور قبل كتابة سطر كود واحد.

## التشغيل السريع

```bash
# فحص مشروع كامل عبر جميع الفاحصات الستة عشر
node scripts/scan-all.mjs /path/to/project

# فحص خصائص العربية واتجاه اليمين إلى اليسار (RTL)
node scripts/scan-rtl.mjs /path/to/project

# تشغيل اختبارات الأنماط والفاحصات
npm test
```
