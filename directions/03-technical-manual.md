# 03 — Technical Manual & Datasheet

## 1. Typography

- **Latin pairing**: IBM Plex Sans Condensed + IBM Plex Sans + IBM Plex Mono
- **Arabic pairing**: IBM Plex Sans Arabic + IBM Plex Mono
- **Scale & measure**: See `references/design/typography.md` (`tabular-nums` required on all figures).

## 2. Color logic

- **Palette tokens**: Specification Gray `#f2f4f5`, Ink `#11161b`, Safety Amber `#d97706`, Grid `#cbd5e1`
- **Distribution**: 60% primary paper surface, 30% primary ink and structural borders, 10% single accent.

## 3. Grid and spatial rhythm

- **Structure**: Dense specification tables, numbered callouts (`FIG. 2.1`), sticky parameter sidebar
- **Vertical pacing**: Alternate compact data sections (`3rem`) with open narrative pauses (`6rem`).

## 4. Imagery rule

- Exploded isometric vector schematics and dimension drawings (`mm` / `tolerance`)

## 5. Motion rule

- Instant 80ms state toggles; zero decorative motion

## 6. Copy voice

- **Tone**: Imperative, quantitative, specification-first

## 7. Fit and anti-fit

- **Best-fit industries**: Hardware manufacturers, CNC machining, developer CLI tools, logistics APIs
- **When NOT to use**: Luxury hospitality or fashion
