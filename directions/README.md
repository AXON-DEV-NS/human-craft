# Design directions selector (12 archetypes)

Never start building with 'modern and clean'. Pick one of these 12 archetypes during Phase 2 (`workflow/02-direction.md`) and lock its constraints in the Direction Statement.

| ID | Archetype | Best-fit industries |
|---|---|---|
| [01 — Editorial Swiss Grid](01-editorial-swiss.md) | Instrument Serif + IBM Plex Sans | Architecture firms, research institutes, financial infrastructure, design studios |
| [02 — Print Broadsheet & Gazette](02-print-broadsheet.md) | Newsreader + Source Sans 3 | Think tanks, legal practices, investigative journalism, literary publishers |
| [03 — Technical Manual & Datasheet](03-technical-manual.md) | IBM Plex Sans Condensed + IBM Plex Sans + IBM Plex Mono | Hardware manufacturers, CNC machining, developer CLI tools, logistics APIs |
| [04 — Tactile Workshop & Craft](04-tactile-craft.md) | Fraunces + Work Sans | Specialty coffee roasters, furniture makers, ceramics, culinary workshops |
| [05 — Gallery & Exhibition Catalog](05-gallery-museum.md) | Syne + Plus Jakarta Sans | Museums, cultural foundations, interior architecture, photography portfolios |
| [06 — Typographic Poster & Monograph](06-type-poster.md) | Familjen Grotesk + Instrument Sans | Conferences, music venues, independent software studios, campaign microsites |
| [07 — Documentary Photographic](07-photographic.md) | Instrument Serif + Source Sans 3 | Field NGOs, agriculture, marine shipping, regional tourism, documentary film |
| [08 — High-Density Operational Ledger](08-data-dense.md) | IBM Plex Sans + IBM Plex Mono | Accounting software, customs brokers, server observability, medical lab portals |
