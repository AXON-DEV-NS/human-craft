# Color systems overview (one-page hub)

Every color in `tokens.json` must trace to a physical or brand source—never to Tailwind's default indigo-violet-pink ramp.

## Core rules

1. **60 / 30 / 10 proportion**: 60% primary paper/surface neutral, 30% secondary structural surface/ink, 10% single high-intent accent.
2. **Consistent neutral temperature**: Mix warm stone/bone neutrals (`#f6f4f0`, `#181816`) or cool slate neutrals (`#f4f6f8`, `#11161b`), never both on the same page.
3. **WCAG 2.2 AA contrast**: Body copy >= `4.5:1` (`7:1` preferred), large headings >= `3.0:1`, interactive borders/focus rings >= `3.0:1`.
